# InventoryProject
This is my Inventory Management System project,,
The Inventory Management System connects Java to a MySQL database using the MySQL JDBC driver.

The system performs CRUD operations on a products table stored in the database inventory_db.

This project demonstrates how a Java program can perform CRUD operations using JDBC and MySQL.
It is easy to understand and is useful for students learning database connectivity in Java. The system successfully manages inventory items and can be expanded later by adding features such as search, login system, billing, or a graphical user interface.
The user interacts with the system through a simple console menu to manage products efficiently.
